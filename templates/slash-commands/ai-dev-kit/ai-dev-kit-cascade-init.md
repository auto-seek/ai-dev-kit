- Project-ID join: `cascade-center-agent/SKILL.md`; only ID and level, then

  `references/project-id-center.md`; use the approved standalone Center release.

- Join a traditional center without project-ID admission: `references/worker-enrollment.md`; discover the
  exact existing entry, verify this device's access and deliver the first join's
  report once. Reuse matching reports and unchanged machine checks across
  sessions; register only an identity change when the project requires it.
- Migration or access failure: `references/center-access.md`; preserve
  history/ownership, repair actual access, and verify each participant. Do not
  waive coordination/preflight or merge first because tests passed.
- Unspecified local setup: the init skill's local storage/role wizard.

The traditional-route references live under the core ai-dev-kit skill. The
project-ID center reference lives under the init skill. The following runtime
and doctor instructions apply only to the traditional route. Installation uses that
project's approved immutable source and capability checks, with Cascade 0.8.1 as
the default release and the >=0.8.0 new-install requirement retained. Company mirrors and
reviewed wheels do not require a GitHub account and are not error fallbacks.
Bootstrap preserves existing profiles byte for byte; only an approved migration
changes their version requirements.

Use the enrollment reference's `lane doctor --python <actual-Cascade-Python>`
for a changed or unverified actual entrypoint and retain that interpreter for
later lane operations. It is not a report, admission certificate or proof that
other clients stopped. Local setup errors block the affected worker; uncontained
incompatible clients still block the affected shared protocol migration.

Follow the selected route's isolated and effective configured-storage checks;
reuse unchanged access/setup evidence as that route permits. No empty replacement
graph, backend downgrade, borrowed credentials or reopening of a fenced old
source. Installation and smoke failures preserve the previous configuration.
